Origins and governance

One system, three layers

RSOS began as a symbolic language for healing, transforming, signalling and evolving. Core is the technical layer that grew from it. The symbolic language compiles to Core, so both describe the same programs, and every Core operation links back to its origin.

An operation enters Core only after it is implemented, tested and backed by an experiment. Today that is seven operations and two state functions. What is measured is the runtime and the planning protocol; whether the spatial syntax itself compresses communication between agents or robots is a planned test (SC1), not yet a result.

Run it

Python 3.10 or later. Core itself uses only the standard library; the package adds the MCP server. Use it as a library, or add it to any MCP client (Claude Code, Cursor and others) with one command.

Core v1 ships in release 0.4.0. Until that release is on PyPI, install from the repository as shown.
