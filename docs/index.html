RSOS Language

A spatial-symbolic programming language for humans and AI. Write a program as a scene: place, pierce, enter, colour, connect. The same program runs as an AI agent and as a person's practised mental model.

The place decides

The same capability at a module's head, heart, brain or beside it gives four different, measured results.

One program, two runtimes

An agent's change and a person's practice session from the same lines, checked for equivalence.

Safety in the compiler

Consent, a constitution of seven checks, safety modes and return to baseline, before anything reaches a person.

Every result reproducible

Pre-registered experiments, seeds and result hashes; the failures are published with the successes.
